# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The TripMate team takes the security of our application and users seriously.

If you believe you have found a security vulnerability in TripMate, please do **NOT** open a public issue. Instead, report it responsibly:

1. Open a private security advisory on GitHub or email the maintainer.
2. Provide detailed steps to reproduce the issue.
3. Include potential impact and affected components.

We will review your submission and respond within 48 hours. Thank you for helping keep TripMate safe!
